# Artefatos de produto

Crie estes arquivos **antes** de implementar. Um por fase.

```
docs/product/
├── 01-problema.md
├── 02-usuario.md
├── 03-escopo.md
├── 04-fluxos.md
├── 05-regras.md
├── 06-arquitetura.md
├── 07-design-system.md
└── 08-ui.md
```

Copie para o projeto:

```bash
mkdir -p docs/product
cp templates/product/*.md docs/product/
```

Preencha na ordem. Só avance quando a fase anterior estiver clara.
